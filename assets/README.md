# Hermes submission artwork

`trurl-constructor.png` is the approved left-facing constructor logo for the Trurl Hermes plugin README and submission artwork.

The 1254 × 1254 PNG includes the TRURL wordmark on white. Preserve its square proportions, facing direction, blue eye and red detail. It is raster artwork, not an SVG or transparent cutout.

This mascot is specific to the Hermes submission. The main Trurl wordmarks, shared visual identity, Taste Atlas and Sunday edition designs remain unchanged.

`atlas-interests-example.svg` and `atlas-connections-example.svg` are reviewed publication illustrations carried forward from Trurl commit `7c3a5e491e4c3de43c543b2e43ffe9fc66eefb79`. They illustrate publication-approved example interests and connections; they contain no raw taste profile or feedback ledger. The shared engine is now pinned separately to `a63cf71900f85fefeb766c5ec051c1e22d11b697`. The plugin's actual Atlas is generated privately from its current Hermes profile.

The README uses four native browser captures in `screenshots/`: Atlas connections, source inspection, the interest map and a Sunday edition. These were generated from release commit `125981544d5463bc8f386181770511573d7ab1b1` using a synthetic profile, with no real user taste data. `CAPTIONS.txt` and `capture-metadata.json` describe the fixture and capture scope; `SHA256SUMS` verifies the four image files. The original screenshot bytes are preserved.
