# Hermes submission artwork

`trurl-constructor.webp` is the lossless README copy of the approved left-facing constructor logo. `trurl-constructor.png` remains available for submission artwork.

Both files retain the original 1254 × 1254 pixels, including the TRURL wordmark on white. Preserve their square proportions, facing direction, blue eye and red detail. This is raster artwork, not an SVG or transparent cutout.

The WebP is **675,544 bytes**, compared with **1,292,715 bytes** for the original PNG. The PNG is losslessly recompressed to **976,454 bytes**. Decoded RGB pixels were checked for exact equality with the original. The derived exports omit the original C2PA credential because its binary binding no longer applies; the original asset remains in Git history.

This mascot is specific to the Hermes submission. The main Trurl wordmarks, shared visual identity, Taste Atlas and Sunday edition designs remain unchanged.

The README uses native screenshots in place of the earlier illustrative Atlas SVGs. The plugin's actual Atlas is generated privately from its current Hermes profile.

The README uses four native browser captures in `screenshots/`: Atlas connections, source inspection, the interest map and a Sunday edition. These were generated from release commit `125981544d5463bc8f386181770511573d7ab1b1` using a synthetic profile, with no real user taste data. `CAPTIONS.txt` and `capture-metadata.json` describe the fixture and capture scope; `SHA256SUMS` verifies the four image files. The original screenshot bytes are preserved.
